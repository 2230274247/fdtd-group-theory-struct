# 群论母结构数据库表结构说明

本数据库采用中文字段名，便于人工维护和论文记录；脚本内部也按中文表头读取。每个具体仿真样本通过“样本编号”连接仿真输入、光谱结果和文件路径。

## 核心表

| 表格文件 | 作用 |
|---|---|
| mother_structures.csv | 记录高对称母结构家族、原始对称群、参数和推荐扰动 |
| perturbation_rules.csv | 记录每类母结构的扰动方式、降群路径和 delta 定义 |
| simulation_samples.csv | 记录具体 FDTD 仿真样本的几何参数和扫描条件 |
| spectrum_metrics.csv | 记录光谱提取后的峰位、半峰宽、Q 值和透过率指标 |
| file_index.csv | 记录新样本对应的模型、光谱文本、场图和脚本路径 |
| inverse_targets.csv | 记录逆向设计目标和候选样本筛选结果 |

## 关联关系

母结构表中的“家族编号”连接扰动规则表和仿真样本表；仿真样本表中的“样本编号”连接光谱结果表和文件索引表。建议后续所有 `.fsp`、光谱 `.txt/.csv`、场图 `.png` 都使用同一个“样本编号”作为文件名前缀。
