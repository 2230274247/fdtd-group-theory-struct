# 群论母结构数据库使用说明

更新时间：2026-04-27 11:33:12

本数据库目录已经改为直观中文命名。正式表格采用“表头 + 一行范例”的模板形式，用来定义字段、关联关系和填写规范。

## 顶层目录

| 目录名 | 存放内容 |
|---|---|
| 文档与说明 | 数据库表结构、扰动定义、命名规则、原始参考文档 |
| 数据表格模板 | 所有核心数据表的单行范例模板和总表 |
| FDTD模型归档 | 后续按对称群和母结构分类存放 `.fsp` 模型 |
| 光谱数据归档 | 后续按对称群和母结构分类存放透射/反射光谱数据 |
| 场图图片归档 | 电场分布图、磁场分布图、模式场分布图 |
| 数据库维护脚本 | 生成样本表、提取光谱指标、绘制规律图的脚本 |
| 分析输出结果 | 规律图表、逆向候选结构、分析报告 |
| 原始文件索引 | 对你原有母结构目录中文件的路径索引 |

## 核心表格

| 表格名 | 作用 |
|---|---|
| 母结构家族表.xlsx | 记录高对称母结构家族的基础信息 |
| 对称扰动规则表.xlsx | 记录扰动方式、delta 定义和降群路径 |
| 仿真样本参数表.xlsx | 记录具体 FDTD 仿真输入参数 |
| 光谱指标结果表.xlsx | 记录峰位、半峰宽、Q 值、透过率等输出指标 |
| 样本文件索引表.xlsx | 记录模型、光谱、场图、脚本等文件路径 |
| 逆向设计目标表.xlsx | 记录目标光谱条件和候选样本 |
| 数据库目录设计表.xlsx | 说明目录分类规则 |
| 字段字典说明表.xlsx | 解释字段类型、含义和维护规则 |
| 群论母结构数据库单行范例总表.xlsx | 上述表格的 Excel 汇总版本 |

## 命名原则

1. 给人看的文件和文件夹使用直观中文名。
2. 表格内部的编号字段仍保留英文编号，例如 `C4_cross`，便于脚本、机器学习和跨文件关联。
3. 每个正式表格只保留一行范例；后续真实数据应在此模板基础上复制扩展。
