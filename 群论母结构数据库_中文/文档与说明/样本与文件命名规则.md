# 样本与文件命名规则

文件夹和表格文件使用直观中文命名；样本编号、母结构家族编号、扰动规则编号保留英文和数字，方便程序处理。

## 样本编号格式

```text
扰动规则编号_四位序号
```

示例：

```text
C4_cross_arm_length_difference_0006
C2_dual_pillars_radius_difference_0003
```

## 文件命名建议

| 文件类型 | 命名示例 |
|---|---|
| FDTD 模型 | C4_cross_arm_length_difference_0006.fsp |
| 透射光谱 | C4_cross_arm_length_difference_0006_T.txt |
| 电场分布图 | C4_cross_arm_length_difference_0006_E.png |
| 磁场分布图 | C4_cross_arm_length_difference_0006_H.png |
| 模式场分布图 | C4_cross_arm_length_difference_0006_mode.png |

## 推荐归档位置

```text
FDTD模型归档/C4/C4_cross_十字/
光谱数据归档/C4/C4_cross_十字/
场图图片归档/电场分布图/C4/C4_cross_十字/
场图图片归档/磁场分布图/C4/C4_cross_十字/
场图图片归档/模式场分布图/C4/C4_cross_十字/
```

这样做的好处是：目录对人直观，编号对程序稳定。
