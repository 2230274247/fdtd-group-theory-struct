# 母结构参数修改建议表（按对称性分类）

> 用途：本文件用于指导后续在 FDTD / Lumerical 中对不同“母结构”进行参数化修改，并记录每个结构样本的对称性、扰动参数、降群路径和预期光谱影响。  
> 适用目标：基于高对称母结构，通过微小形变、位移、开槽、挖孔等方式破坏强对称性，研究其对共振峰位、半峰宽 FWHM、Q 值、透过率以及 Fano / quasi-BIC 线型的影响，最终服务于“目标光谱 → 结构特征与参数”的逆向设计。

---

## 0. 使用原则

### 0.1 不要一开始同时改很多参数

每次仿真优先只改变一个扰动参数，例如只改左右半径差、只改横竖臂长度差、只改单孔半径。这样才能判断：

```text
对称性破缺方式 → 光谱响应变化
```

如果一次同时改半径、位置、厚度、材料，后续很难解释光谱变化来自哪里。

---

### 0.2 建议先采用统一的基准尺寸

为了让 Codex 或后续脚本更容易生成表格，本文先给出一个推荐基准。实际仿真时可以按目标波长整体缩放。

| 参数 | 推荐初始值 | 说明 |
|---|---:|---|
| 周期 `p` | 500 nm | 可作为第一版 400–900 nm 可见光范围的基准周期 |
| 结构厚度 `h` | 160–220 nm | 初始可取 180 nm |
| 背景 | air | 入射侧通常为空气 |
| 衬底 | SiO2 | 可根据实际结构修改 |
| 结构材料 | TiO2 / Si / Al2O3 等 | 建议先选一种高折射率介质，减少材料变量 |
| 光谱范围 | 400–900 nm | 先覆盖可见光与近可见区 |
| 扰动强度 `delta` | 0–0.20 | 先粗扫；若出现窄峰，再细扫 0–0.06 |

---

### 0.3 扰动强度 delta 的推荐取值

建议第一轮使用：

```text
delta = 0, 0.02, 0.04, 0.06, 0.08, 0.10, 0.12, 0.16, 0.20
```

其中：

- `delta = 0`：高对称母结构；
- `delta > 0`：对称性被破坏；
- 小 `delta` 区域更容易观察 quasi-BIC / 高 Q 趋势；
- 大 `delta` 区域更容易出现强辐射泄露、宽线宽、峰位偏移或多峰。

如果发现 `delta = 0.02–0.06` 附近出现尖峰，建议第二轮细扫：

```text
delta = 0, 0.005, 0.010, 0.015, 0.020, 0.025, 0.030, 0.040, 0.050, 0.060
```

---

### 0.4 推荐 CSV / Excel 字段

建议 Codex 生成表格时，每一行表示“一个可扫描参数”。

```text
category,
structure_name,
base_group,
recommended_priority,
base_parameters,
perturbation_name,
changed_parameter,
scan_start,
scan_end,
step,
delta_definition,
perturbed_group,
symmetry_path,
expected_spectral_effect,
notes
```

字段含义：

| 字段 | 含义 |
|---|---|
| `category` | 结构大类，例如 C2、C4、C6、近径向 |
| `structure_name` | 母结构名称 |
| `base_group` | 母结构对称群，例如 C2、C4、C6、C∞_approx |
| `recommended_priority` | 推荐优先级，A 最高，B 次之，C 适合后续扩展 |
| `base_parameters` | 母结构的基准参数 |
| `perturbation_name` | 扰动名称，例如半径差、偏心孔、单裂缝 |
| `changed_parameter` | 具体改变的参数 |
| `scan_start` | 扫描起始值 |
| `scan_end` | 扫描结束值 |
| `step` | 扫描步长 |
| `delta_definition` | 归一化扰动强度定义 |
| `perturbed_group` | 扰动后对称群 |
| `symmetry_path` | 降群路径 |
| `expected_spectral_effect` | 预期对光谱的影响 |
| `notes` | 建模注意事项 |

## 1. 近径向高对称母结构

这一类结构在孤立状态下接近连续旋转对称，可记为 `C∞_approx`。但放入周期晶格后，整体对称性还要受到晶格影响。例如放在正方晶格中，整体系统往往更接近 C4 或 C4v 的约束。因此这一类结构适合作为“高对称参考组”，但不建议作为第一条主线。

---

### 1.1 圆盘

**母结构对称性：** `C∞_approx`  
**推荐优先级：** B  
**基准参数建议：**

| 参数 | 建议值 |
|---|---:|
| 周期 `p` | 500 nm |
| 圆盘半径 `R` | 90–130 nm，初始 110 nm |
| 厚度 `h` | 180 nm |

| 推荐扰动 | 改变参数 | 起始值 | 结束值 | 步长 | delta 定义 | 降群路径 | 预期影响 |
|---|---|---:|---:|---:|---|---|---|
| 偏心孔 | 孔中心偏移 `d` | 0 nm | 60 nm | 5–10 nm | `delta = d / R` | `C∞_approx -> C1`，若沿晶格轴偏移可近似保留镜面对称 | 打开原本弱耦合模态的辐射通道，可能形成 Fano 型窄峰/窄谷；偏移越大，线宽通常越宽 |
| 单侧缺口 | 缺口深度 `notch_depth` | 0 nm | 40 nm | 5 nm | `delta = notch_depth / R` | `C∞_approx -> C1` | 局部散射增强，可能使暗模变亮；过大时容易引入宽峰和杂散模 |
| 局部槽 | 槽宽 `slot_w` | 0 nm | 30 nm | 5 nm | `delta = slot_w / R` | `C∞_approx -> C1` | 改变局部场集中区域，增强模式泄露；适合观察场从圆盘边缘泄露的过程 |
| 椭圆化 | `Rx - Ry` | 0 nm | 40 nm | 5 nm | `delta = (Rx - Ry) / R` | `C∞_approx -> C2` | 连续旋转对称降为二重旋转对称，峰位可能发生明显分裂或偏移 |

## 2. C2 母结构

C2 结构是最建议优先做的主线。它的参数少、降群路径直接，最适合先建立 `Q ~ 1/delta^2` 或类似趋势。

---

### 2.1 双柱

**母结构对称性：** `C2`  
**推荐优先级：** A  
**基准参数建议：**

| 参数 | 建议值 |
|---|---:|
| 周期 `p` | 500 nm |
| 柱半径 `r0` | 50–80 nm，初始 65 nm |
| 两柱中心距 `s` | 130–180 nm，初始 150 nm |
| 厚度 `h` | 180 nm |

| 推荐扰动 | 改变参数 | 起始值 | 结束值 | 步长 | delta 定义 | 降群路径 | 预期影响 |
|---|---|---:|---:|---:|---|---|---|
| 左右半径差 | `r1-r2` | 0 nm | 25 nm | 2.5–5 nm | `delta=(r1-r2)/r0` | `C2 -> C1` | 最推荐。会打开暗模辐射通道；小扰动区可能出现高 Q 窄峰，扰动增大后 FWHM 增大 |
| 左右位置差 | 左柱或右柱偏移 `dx` | 0 nm | 30 nm | 5 nm | `delta=dx/s` | `C2 -> C1` | 改变两柱耦合距离，峰位和线宽都会变；容易造成模式局域在一侧 |
| 间距扫描 | 中心距 `s` | 110 nm | 210 nm | 10 nm | `delta=(s-s0)/s0` | 通常保持 `C2` | 主要调节耦合强度和峰位，不是强降群参数；适合作为第二层优化 |
| 高度差 | `h1-h2` | 0 nm | 40 nm | 5 nm | `delta=(h1-h2)/h0` | `C2 -> C1` | 改变有效折射率与模式频率，可能引入明显峰位移动 |

## 3. C3 母结构

C3 结构理论上较漂亮，但通常比 C2、C4 难解释。建议在 C2 或 C4 路线得到稳定结果后再扩展。

---

### 3.1 三柱簇

**母结构对称性：** `C3`  
**推荐优先级：** B

## 6. 推荐优先级总结

### 6.1 第一阶段最推荐

| A | 十字 | 横竖臂长度差 | 建立 `C4 -> C2` 降群主线 |
| A | 方环 | 偏心内孔或单裂缝 | 研究环模泄露和 Fano 线型 |

## 9. 后续最重要的三张图

当你完成第一批仿真后，优先画：

```text
delta - Q_factor
delta - FWHM
delta - T_peak
```

如果某一类结构中出现：

```text
delta 增大 → FWHM 增大 → Q 下降
```

或者出现近似：

```text
Q ∝ 1 / delta^2
```

那么这条结构路线就值得继续深入。它可以作为“对称性破缺调控辐射泄露”的核心证据。

## 10. 最终目标

这套表格不是为了机械扫描参数，而是为了建立下面这条数据链：

```text
母结构类型
→ 原始对称群
→ 扰动方式
→ 降群路径
→ 扰动强度 delta
→ 光谱峰位 / FWHM / Q / 透过率
→ 目标光谱反向筛选结构
```

也就是说，最终希望模型不只是学习：

```text
几何参数 → 光谱
```

而是进一步学习：

```text
对称性家族 + 降群路径 + 扰动强度 + 几何参数 → 光谱响应
```

这样你的逆向设计就不是纯黑箱，而是带有物理先验的结构逆向设计。
