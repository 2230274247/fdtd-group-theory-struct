# 经验文档库

这个目录专门放给智能体或 AI 看的经验文档。目标不是堆项目记录，而是把“目标光谱 -> 机制匹配 -> 结构选择 -> 仿真验证 -> 失败回退”整理成可直接复用的规则。

## 目录结构

```text
经验文档库/
  00_机器可读/
  01_机制总则/
  02_家族速查/
  03_项目复盘/
  04_AI行动规则/
```

## 适用方式

1. 先读 [00_机器可读/index.json](./00_机器可读/index.json)，快速知道该看哪些文件。
2. 再读 [00_机器可读/mechanisms.json](./00_机器可读/mechanisms.json) 和 [00_机器可读/families.json](./00_机器可读/families.json)，先做机制和结构族筛选。
3. 如果目标和当前 D4 项目类似，读 [00_机器可读/d4_case.json](./00_机器可读/d4_case.json)。
4. 执行仿真时遵守 [00_机器可读/rules.json](./00_机器可读/rules.json) 和 [04_AI行动规则/自动化优化工作规范.md](./04_AI行动规则/自动化优化工作规范.md)。
5. 如果需要人类可读的解释，再读 [01_机制总则/机制与谱型总表.md](./01_机制总则/机制与谱型总表.md)、[02_家族速查/群论结构族选择速查.md](./02_家族速查/群论结构族选择速查.md)、[03_项目复盘/D4准BIC项目经验与失败模式.md](./03_项目复盘/D4准BIC项目经验与失败模式.md)。
