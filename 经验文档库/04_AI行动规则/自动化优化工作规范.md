# 自动化优化工作规范

这份文档是给 AI 的操作规程。目标是避免无缘由试错，避免并行仿真，避免“看起来做了很多，实际上什么也没验证”。

## 1. 硬性规则

1. 任何真实 FDTD 仿真前都必须确认当前没有其他 `.fsp` 在运行。
2. 同一时刻只能运行一个仿真线程。
3. 每一次参数改动都必须有物理依据。
4. 没有依据的改动次数，不应超过 3 次，且必须在文档中明确标记为“探索性尝试”。
5. 所有有价值的 `.fsp`、日志、Excel、PNG 都必须保留。

## 2. 推荐工作流

```text
目标输入
-> 机制判定
-> 结构族选择
-> 公式估算
-> 单变量构造
-> 单线程仿真
-> 结果评估
-> 失败模式反推
-> 下一轮只改一个主变量
```

## 3. 先看什么，再决定什么

### 3.1 先看目标

- 单峰还是多峰
- 峰高还是背景更重要
- 是透射峰还是反射谷
- 允许多大 FWHM
- 是否允许旁峰

### 3.2 再看机制

- 准 BIC
- 屏蔽层
- DBR 缺陷腔
- EIT-like 耦合
- 近径向 WGM-like

### 3.3 再看结构族

- C2：最简单的破缺
- C3：角向控制
- C4：最好做单峰主线
- C6：更高阶角向模式
- 近径向：WGM-like 起点
- D4：低背景高峰综合最强

## 4. 单变量原则

每一轮只允许一个主变量变化。

可以同时固定的东西：

- 材料
- 边界条件
- 波长范围
- 监视器定义
- 评价指标

可以变化的主变量：

- `eta`
- `slit width`
- `aperture length`
- `inner/outer shift`
- `thickness`
- `hole radius`

但每轮只能选一个。

## 5. 什么时候该停止某条路径

如果出现以下任一情况，就不应继续这条路径：

- 峰高连续两轮下降。
- 背景连续两轮上升。
- 峰位开始跑到边界。
- 新结果变成多峰。
- 数值发散或未收敛。

这时应该切换机制，而不是继续硬调参数。

## 6. 评价顺序

不要只看峰高。建议评价顺序如下：

1. 是否发散。
2. 是否有多峰。
3. 峰位是否在目标范围。
4. 背景是否足够低。
5. 峰是否足够高。
6. 峰宽是否足够窄。

也就是说，先排除“坏结果”，再在好结果里比优劣。

## 7. 结果记录模板

每次仿真后都要记录：

- 结构族
- 参数
- 物理假设
- 峰高
- 峰位
- FWHM
- 背景 p95
- 是否有旁峰
- 是否收敛
- 下一轮计划

## 8. 推荐给 AI 的失败处理方式

如果当前尝试失败，AI 不应该：

- 继续随机扫参。
- 同时改多个变量。
- 只盯峰高不管背景。
- 把发散结果当成峰。

AI 应该：

- 判断失败属于损耗问题、耦合问题、对称性问题还是数值问题。
- 根据失败类型换机制，或者只微调一个参数。

## 9. 推荐的探索次数上限

对于没有明确依据的动作，建议规则如下：

- 最多 3 次。
- 每次都要写清楚为什么做。
- 如果三次后没有方向，就停止这条路径，回到机制层重选。

## 10. 简短结论

这个项目里最有价值的经验不是某个参数值，而是：

```text
物理机制优先
单线程验证
单变量更新
失败先归因
再决定是否继续
```
