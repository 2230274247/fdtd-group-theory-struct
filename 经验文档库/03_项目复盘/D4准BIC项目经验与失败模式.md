# D4 准 BIC 项目经验与失败模式

这份文档专门总结本次 D4 双环八缝耦合腔项目。面向 AI 的目标是：以后看到类似目标谱时，能快速知道这个结构族为什么有效、哪些改动是有效的、哪些改动应该立刻停止。

## 1. 最终结论

当前最优版本：

- 金属屏材料：`Ag (Silver) - Palik (1-10um)`
- 金属厚度：`90 nm`
- 对角失谐：`eta = 6.60 nm`
- 屏蔽开口宽度：`36 nm`
- 屏蔽开口径向额外长度：`110 nm`

对应谱线：

- `peak_abs2 = 0.8327`
- `FWHM = 3.02 nm`
- `offband_p95 = 0.01031`

这已经满足“单峰、尖、背景低、峰高强”的核心要求，且是经过单线程逐轮验证得到的，不是偶然碰到的。

## 2. 这个结构为什么能工作

它由三部分共同决定：

1. D4 对称的双环硅暗模提供高 Q 的本体。
2. 对角失谐 `eta` 把对称保护模弱打开，形成可辐射通道。
3. Ag 金属屏蔽层压低背景，同时开口长度控制外耦合强度。

可以把它近似理解成：

```text
低背景屏蔽 + 准 BIC 暗模 + 临界耦合调节
```

对应耦合模关系：

```text
T_peak ~= 4 gamma_top gamma_bottom / (gamma_i + gamma_top + gamma_bottom)^2
```

这里：

- `gamma_i` 代表吸收损耗。
- `gamma_top/gamma_bottom` 代表端口耦合。
- 本项目的关键不是只压低 `gamma_i`，而是让耦合更接近临界点。

## 3. 全流程中最重要的几个问题

### 3.1 网格收敛问题

mesh=1 时的一个点看起来非常好，但当用户把 mesh accuracy 改成 2 后，峰值显著塌缩。

原因不是“结构彻底失效”，而是原结构里有极窄的金属缝没有被充分解析。

解决方法：

- 先放弃不可收敛的超窄缝方案。
- 把结构改成 mesh=2 可解析的几何。

成效：

- 让后续结果可验证。
- 避免在未收敛结构上继续浪费时间。

### 3.2 直接用 PEC 作为上限诊断

PEC 的目的只是判断“如果不考虑金属损耗，峰可能被推到什么程度”。

结果是场发散，谱线数值异常，说明：

- PEC 不能当最终结论。
- 它只是一种诊断工具。

AI 以后看到这种情况，不能把 PEC 当成可制造方案。

### 3.3 盲目减薄金属层

把 Ag 从 90 nm 减到 70 nm 后，结果变差：

- 峰从 `0.287` 降到 `0.205`
- 背景反而升高

这说明金属层不只是吸收层，它还承担背景屏蔽和边界相位控制。

结论：

- 金属厚度不是越薄越好。
- 这条路径应停止。

### 3.4 真正有效的是开口长度重叠

把屏蔽开口从原始长度逐步增加后，峰高显著上升：

- extra90：`peak_abs2 = 0.6502`
- extra110：`peak_abs2 = 0.8327`

这说明真正起作用的是：

- 开口和暗模的重叠更好了。
- 外耦合更接近临界耦合。

而不是随便变大孔或者减薄金属。

## 4. 本项目中的失败模式

| 失败模式 | 现象 | 原因判断 | 处理 |
|---|---|---|---|
| 窄缝未收敛 | mesh=2 后峰塌缩 | 原结构最窄缝太小 | 重建为可解析几何 |
| PEC 发散 | 谱线异常大 | 不是物理峰，而是数值发散 | 仅保留为诊断 |
| Ag70 变差 | 峰变低、背景变高 | 屏蔽不足，泄漏通道打开 | 停止减薄 |
| 只改 slit 宽度 | 背景抬升明显 | 非共振通道被打开 | 不再盲调宽度 |
| 参数映射 bug | 声明与几何不一致 | `extra_length` 没更新到实际长度 | 修正脚本逻辑 |

## 5. 本项目中有效的动作

| 有效动作 | 为什么有效 | 结果 |
|---|---|---|
| Au -> Ag | 降低真实欧姆损耗 | 峰高上升，背景仍可控 |
| 保持 Ag90 | 保留屏蔽和相位匹配 | 比 Ag70 更优 |
| 增大 aperture extra length | 增强暗模-开口耦合重叠 | 峰高显著上升 |
| 逐次单变量验证 | 能解释每一步 | 避免无意义扫参 |

## 6. 后续还可以怎么继续

如果还想往前走，应该只做两类动作：

1. 背景清理，不破坏峰高。
2. 轻微的局部微调，不改变机制。

不建议继续做：

- 金属厚度的随机扫参。
- 没有机制解释的高度/宽度瞎改。
- 同时改多个变量。

## 7. 对 AI 的操作规则

AI 在后续做这个家族时，应该按下面顺序：

1. 先确认目标是单峰还是多峰。
2. 先确认背景是否要压到接近零。
3. 先确认是否允许金属屏蔽层。
4. 再用公式估算 `R_eff`、`eta`、开口长度。
5. 每次只改一个主变量。
6. 每轮只验证一个物理假设。

## 8. 可以直接复用的经验

- D4 很适合做“低背景单尖峰”的主战场。
- 真正有效的调参方向是“耦合匹配”，不是“越强越好”。
- 背景一旦被打开，后续要先回到背景机制，不要只盯峰。
- 参数必须和实际几何一一对应，脚本里不能只改名字不改结构。

## 9. 这次项目给出的结论

这个项目最终证明了一件事：

```text
高对称暗模 + 可控降群 + 金属屏蔽 + 临界耦合
```

确实可以把“背景干净、峰尖、峰高强”三件事同时做到较好水平。

但是它也证明了另一件同样重要的事：

```text
只改一个变量才知道为什么成功
```

这就是后续所有 AI 优化应当遵守的底层原则。
