# FDTD 群论结构结果查看器

这个工具用于浏览和分析：

`H:\FDTD outcome\struct\群论_struct`

## 启动

在 PowerShell 里运行：

```powershell
cd "H:\FDTD outcome\struct\群论_struct\结果查看器_html"
python .\server.py
```

然后打开：

```text
http://127.0.0.1:8787/
```

## 主要功能

- 默认进入“总控”页面，查看有效 run、谱线总数、不收敛数量和扰动结果覆盖情况。
- 左上角“有效 run / 谱图 / 不收敛”三个统计块可以点击，用来快速切换总控里的对应明细。
- 总控中的状态表按“大类 → 母结构 → 扰动”三级折叠展示；大类和母结构前方的圆点表示已有结果的进度。
- 展开某个母结构后，每个小扰动会用单独状态点标记是否已有最新结果，并显示谱图数、不收敛数量和最差 `maxT`。
- 总控会额外展示收敛比例、母结构覆盖、风险最高母结构和最新 run，方便先做全局判断。
- 总控会按 run 聚合展示不收敛风险，数量越多颜色越醒目。
- 可将 `run_full_*` 文件夹一键删除到 Windows 回收站。
- 可查看每个母结构/扰动脚本文件夹是否已有最新 `run_full_*` 结果，绿色表示已有，红色表示暂无。
- “网页总控”按“大类 → 母结构 → 扰动脚本”折叠展示，可批量或单独启动脚本。
- 网页总控中每个脚本都有独立 `start / end / step` 输入，数值按 `5nm`、`5°` 这类形式显示；顶部不再提供统一扫描参数，避免误改全部结构。
- “结果管理”按“大类 → 母结构 → 扰动目录”分层展示，可整理全部/选中目录，也可集中执行移动不收敛、删除已看、删除未看等清理操作。
- 自动识别 `Transmission_abs2` / `T_abs2`，并计算 `min_T`、`max_T` 及对应波长。
- 若 `max(T)>1`，对应扫描点和 run 会标红，标记为“不收敛”。
- 侧边栏按真实目录层级展开/收起，并在 run 下方高亮展示“降群路径”。
- 支持打开对应 run 的本地文件夹。
- 支持查看单张 PNG 谱图、全部曲线、勾选后的趋势对比图和指标表。
- 在“谱图”页可以点击“自动播放”逐张播放 PNG 透射谱，也可以用“上一张 / 下一张”手动切换；切到其他页面会自动暂停。
- 仿真继续产生新结果后，点击右上角“重新扫描”即可更新。
