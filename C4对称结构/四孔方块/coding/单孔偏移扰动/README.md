# 四孔方块 / 扰动 3：单孔偏移

## 脚本位置

`run_fdtd_single_hole_offset_sweep.py`

## 脚本实现内容

本脚本用于移动四孔方块中的单个空气孔中心位置，孔半径保持母版值不变。默认移动右上角孔，即 `air_hole` 索引 4。

每个扫描点都会：

1. 从源 `.fsp` 的工作母版复制一个独立副本；
2. 在副本中修改目标孔的 `x/y` 坐标；
3. 运行 FDTD；
4. 保存本点 `.fsp`、透射谱 abs^2 图片和 Excel 源数据。

## 降群路径

`C4 -> C1`

单孔偏移同时破坏孔径分布和孔位分布的四重旋转对称，是强局域扰动。它适合用来观察暗模辐射通道被打开、谱线变宽、Fano 型峰谷增强等现象。

## 从母版 .fsp 读取到的结构参数

- Si 方块尺寸：600 nm x 600 nm
- Si 方块厚度：420 nm
- SiO2 衬底尺寸：900 nm x 900 nm
- SiO2 衬底厚度：1000 nm
- 母版孔半径：55 nm
- 母版半孔距：160 nm
- 默认偏移孔：索引 4，右上角孔

## 用户主要可修改参数

- `OFFSET_HOLE_INDEX`：选择要偏移的孔，默认 `4`
- `OFFSET_DIRECTION`：偏移方向，默认 `(1.0, 0.0)`，即 +x 方向
- `OFFSET_START_M`：偏移距离起点，默认 `0e-9`
- `OFFSET_STOP_M`：偏移距离终点，默认 `80e-9`
- `OFFSET_STEP_M`：手动偏移步长，默认 `10e-9`
- `AUTO_STEP`：是否自动计算步长
- `TARGET_POINTS`：自动步长目标点数
- `EDGE_CLEARANCE_M`：孔边缘与方块边界的最小安全距离
- `SIMULATION_TIME_S`：仿真时间
- `RUN_MODE`：运行模式

脚本会根据孔半径、方块边界和安全余量自动裁剪最大偏移距离，避免孔跑出 Si 方块边界。

## 结果保存位置

结果统一保存到：

`H:\FDTD outcome\struct\群论_struct\C4对称结构\四孔方块\results\单孔偏移扰动\run_模式_时间戳\`

源 `.fsp` 受 SHA256 指纹保护，脚本运行期间不会被修改。
