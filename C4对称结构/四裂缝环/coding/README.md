# 四裂缝环扰动自动化脚本说明

本目录包含四裂缝环结构的 5 个扰动脚本：

1. 改单裂缝宽度扰动：C4 -> C1
2. 对边裂缝成对变化扰动：C4 -> C2
3. 裂缝角度差扰动：C4 -> C1
4. 裂缝长度差扰动：C4 -> C1
5. 四裂缝同步扫描扰动：保持 C4

公共流程在 `four_slit_ring_common.py`。

结果统一保存到：

`H:\FDTD outcome\struct\群论_struct\C4对称结构\四裂缝环\results\扰动名\run_模式_时间戳\`

源 `.fsp` 不会被修改。脚本会先复制源文件到 results 下作为工作母版，再复制到英文镜像目录运行。每个扫描点结束后会实时输出 max/min |T|² 及对应波长。
