# 十字扰动 4：单臂开槽自动化仿真

本文件夹用于实现 `十字 / 扰动 4：单臂开槽` 的 FDTD 自动化扫描。在水平臂 +x 端动态添加一个空气矩形（etch），模拟开槽效果。

## 扰动定义

- **扰动名称**：单臂开槽
- **改变参数**：空气槽深度 slot_depth
- **槽位置**：水平臂 +x 端
- **槽宽度**：贯穿整个水平臂宽度（160 nm）
- **降群路径**：C4 -> C1/Cs
- **默认扫描范围**：0 nm 到 200 nm，步长 10 nm
- **slot_depth = 0** 时无槽，为基线结构

## 运行模式

命令行：`--preview`、`--test-run`、`--full-run`、`--resume`
