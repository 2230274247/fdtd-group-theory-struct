# 从原理到结构推导

## 目标光谱

目标不是普通谐振峰，而是“带外几乎不透射、只在一个很窄波长窗口向上透射”的谱线。适合的物理图像是：先做一个低背景透射的周期性高折射率超表面，再用一个弱辐射暗模打开窄带透射通道。

近似目标可以写成：

```text
T(lambda) ~= T_bg + T_pk / (1 + 4 * ((lambda - lambda0) / FWHM)^2)
```

其中希望 `T_bg -> 0`、`T_pk` 尽量大、`FWHM` 尽量小。

## 机制 1: 对称保护 BIC / 准 BIC

在正入射、周期结构的 Gamma 点，外界平面波只能耦合到满足同一对称表示的模态。若结构具有 D4 对称性，某些环形驻波暗模与正入射平面波的对称性不匹配，耦合积分为零：

```text
kappa = integral Delta_epsilon(r) * E_dark(r) dot E_rad(r) dV = 0
```

当结构被小扰动 `delta` 破坏对称性后：

```text
kappa proportional to delta
gamma_rad proportional to |kappa|^2 proportional to delta^2
Q_rad proportional to 1 / delta^2
```

所以小的对称破缺会产生窄线宽。这里把对角裂缝成对失谐定义为 `eta`，归一化扰动为：

```text
delta = eta / R_eff
```

## 机制 2: 环形暗模的尺寸估计

环形谐振的第一估计：

```text
lambda0 ~= 2*pi*n_eff*R_eff / m
```

为使结构不太大，同时让暗模具有 D4 下的非平凡表示，取方位阶数 `m = 2`。扫描波段设为 900-1700 nm，希望中心在约 1350 nm。第一轮仿真显示谱峰贴近 1700 nm 上边界，说明最初的 `n_eff` 估计偏低；第二轮将硅/二氧化硅复合导模有效折射率修正为 `n_eff ~= 1.90`。于是：

```text
R_eff ~= m*lambda0/(2*pi*n_eff)
      ~= 2*1350/(2*pi*1.90)
      ~= 226 nm
```

因此外环使用约 110 nm 环宽，得到：

```text
R_outer_inner ~= 171 nm
R_outer_outer ~= 281 nm
```

这个半径能放入 900 nm 周期内，并在目标波段附近支持环形驻波。

## 机制 3: 低背景透射

只有暗模还不够；如果背景本来就高，窄峰不会显得“其余波长几乎为 0”。因此结构采用高填充比硅外环和内环，形成宽的反射/散射背景。中心盘和四条轴向桥用于调节内外环耦合，形成类似 EIT 的窄带通道。

可用二端口时域耦合模近似理解：

```text
da/dt = (i*omega0 - gamma_i - gamma_rad) a + kappa*s_in
T(omega) = |t_bg + A/(i*(omega - omega0) + gamma_i + gamma_rad)|^2
FWHM_omega ~= 2*(gamma_i + gamma_rad)
```

想要窄峰，需要 `gamma_rad` 小；想要峰向上，需要暗模与低背景通道发生相干透射，而不是只产生一个吸收/反射谷。

前两轮单点仿真显示纯硅环结构的背景透射仍接近 0.9，因此第三轮加入金属屏蔽层。金属层提供低背景：

```text
T_bg_metal << 1
```

然后在金属层中开 D4 对称的 8 个径向环缝孔径，孔径与上方硅环暗模近场耦合。这样目标从“在高背景上产生 Fano 起伏”改为“在低背景屏蔽层上通过暗模打开窄带通道”，更符合向上尖峰的需求。

## 由公式得到的结构

由上面约束得到的母结构命名为“双环八缝耦合腔”：

- 外层: D4 对称的 8 段硅环弧。8 个裂缝提供足够自由度，但整体按 D4 组织。
- 内层: 4 段硅环弧，用于调节与外环暗模的近场耦合。
- 中心: 硅盘加四条轴向桥，控制宽背景和内外环的混合。
- 背景屏蔽: 90 nm Au 薄膜，带 8 个 D4 对称径向环缝孔径，用来把带外透射先压低。
- 扰动: 对角裂缝成对失谐。45/225 度裂缝加宽，135/315 度裂缝变窄，或反向等效。

脚本中的候选不再是任意枚举，而是围绕：

```text
target_Q ~= lambda0 / FWHM_target
delta ~= sqrt(1 / target_Q)
eta ~= delta * R_eff
```

生成一组 `eta`，再配合裂缝基宽和内环半径微调。

## 需要仿真验证的风险

这些公式只给出初值，不保证一次命中完美光谱。主要不确定性有：

- `n_eff` 只是估计，实际共振峰可能偏移。
- 材料损耗和网格误差会限制最大峰值和最小线宽。
- 如果背景透射没有压低，窄峰会变成 Fano 起伏而不是接近理想带通。
- 如果扰动太小，峰可能非常窄但峰值低；扰动太大，峰值可能上升但 FWHM 变宽。

因此后续仿真应先做小规模试扫，根据峰位和背景再修正 `R_eff`、裂缝基宽和 `eta` 范围。

## 已完成的反馈修正

第一轮单点结果：

```text
eta = 11.50 nm, gap = 22.0 nm
peak_abs2 = 0.9540 @ 1694.98 nm
offband_p95_abs2 = 0.9096
FWHM = inf
```

判断：

- 峰位贴近 1700 nm 上边界，不是目标中心附近的窄带透射。
- 带外透射过高，背景没有被压低。

修正：

- 将 `n_eff` 从 1.51 提高到 1.90，按公式缩小环半径。
- 将裂缝基宽候选向更窄范围移动，提高硅填充和背景散射。
- 略收紧内外环间距，使暗模和宽背景通道的耦合更强。

第二轮结果仍然显示背景过高：

```text
eta = 9.13 nm, gap = 14.0 nm
peak_abs2 = 0.9594
offband_p95_abs2 = 0.8982
FWHM = inf
```

因此第三轮加入 Au 低背景屏蔽层，并让金属层孔径与硅环暗模共享同一个 D4 对称破缺参数 `eta`。
