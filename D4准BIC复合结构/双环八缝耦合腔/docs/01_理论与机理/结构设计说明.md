# 双环八缝耦合腔结构设计说明

## 命名

- 结构族: D4准BIC复合结构
- 母结构: 双环八缝耦合腔
- 寻优扰动: 对角失谐准BIC寻优

## 设计意图

这个结构把高对称的 D4 平面点群作为母结构：外层由 8 段硅环弧组成，内层由 4 段硅环弧、中心硅盘和四条轴向耦合桥组成。严格 D4 对称时，部分模态在正入射平面波下近似禁戒耦合；对角裂缝成对失谐后，对称性降到 C2/C1，暗态被微弱打开，目标是形成很窄的向上透射峰。

更详细的公式推导见 `从原理到结构推导.md`。当前母结构半径来自 `lambda0 ~= 2*pi*n_eff*R_eff/m`，失谐扫描来自准 BIC 的 `Q_rad proportional to 1/delta^2` 标度。

本轮命中结果和后续复用方法分别记录在：

- `双环八缝耦合腔_尖峰光谱报告.md`
- `尖峰光谱结构生成经验文档.md`

## 自动尝试逻辑

`coding/对角失谐准BIC寻优/run_fdtd_diagonal_detune_autosearch.py` 会生成并保留：

- `fsp/d4_double_ring_eight_slit_seed.fsp`: 原始 D4 母版。
- `results/对角失谐准BIC寻优/run_*`: 每轮尝试的候选 `.fsp`、透射表格、谱线图和评分日志。

评分不是只看峰值，而是同时检查：

- 峰值透射 `peak_abs2`
- 半峰宽 `fwhm_nm`
- 带外 95 分位透射 `offband_p95_abs2`
- 峰值与带外的对比度 `contrast_vs_p95`
- 峰位是否离扫描边界足够远

## 运行入口

只生成母版和候选计划：

```powershell
python .\coding\对角失谐准BIC寻优\run_fdtd_diagonal_detune_autosearch.py --preview
```

小规模真实仿真：

```powershell
python .\coding\对角失谐准BIC寻优\run_fdtd_diagonal_detune_autosearch.py --test --max-trials 2
```

完整尝试：

```powershell
python .\coding\对角失谐准BIC寻优\run_fdtd_diagonal_detune_autosearch.py --full
```
