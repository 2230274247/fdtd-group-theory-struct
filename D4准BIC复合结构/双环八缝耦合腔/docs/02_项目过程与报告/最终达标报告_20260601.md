## 物理机制

这个结构不是靠单纯增加开口面积得到透射，而是把三个条件叠加起来：

1. `Au` 屏蔽层压低直通背景。
2. `D4` 双环提供对称保护的暗模，形成高 Q 准 BIC。
3. 对角八缝失谐和内环负失谐共同调节外耦合，使暗模在一个窄波段向外辐射。

尺度估算：

```text
lambda0 ~= 2*pi*n_eff*R_eff/m
R_eff ~= m*lambda0/(2*pi*n_eff)
```

取 `lambda0 ~= 1350 nm`、`m = 2`、`n_eff ~= 1.90`，得到 `R_eff ~= 226 nm`。

准 BIC 泄漏关系：

```text
delta = eta/R_eff
gamma_rad proportional to delta^2
Q_rad proportional to 1/delta^2
FWHM ~= lambda0/Q
```

本次 `eta ~= 9.14 nm`，`delta ~= 0.0404`。这个量级给出了几 nm 级线宽；实际结果 `FWHM ~= 2.67 nm`。

内环 `-10 nm` 不是为了增加背景开口，而是改变内外双环之间的近场相位和阻抗匹配。对比结果：

```text
inner_shift = 0 nm:   peak = 0.6543, FWHM = 2.79 nm, p95 = 0.00128
inner_shift = +10 nm: peak = 0.3165, FWHM = 3.07 nm, p95 = 0.00100
inner_shift = -10 nm: peak = 0.8666, FWHM = 2.67 nm, p95 = 0.00311
```

说明该峰值提高主要来自暗模和外部通道的相位匹配改善，而不是粗暴增强开口。

## 失败尝试记录

`eta = 12 nm`：

```text
peak = 0.4204
FWHM = 1.96 nm
p95 = 0.000731
```

结论：继续增大失谐没有增强峰值，反而破坏了匹配。

`gold_thickness = 80 nm`：

```text
peak = 0.01254
FWHM = 19.49 nm
p95 = 0.00211
```

结论：金膜厚度参与缝道纵向相位匹配，不能简单理解成越薄越好。

`inner_shift = +10 nm`：

```text
peak = 0.3165
FWHM = 3.07 nm
p95 = 0.00100
```

结论：内环调相方向错误，降低了模式到出射通道的相干叠加。

`chirped DBR defect cavity`：

```text
peak 可接近 1
但宽波段内出现多个高窄旁峰
```

结论：DBR/Fabry-Perot 机制能给强峰，但宽波段单峰性不如当前 D4 准 BIC 方案。

## 后续优化建议

若还要继续追求更高峰值，优先围绕当前达标点做小步扫描：

```text

gold_thickness: 88, 90, 92 nm
screen_aperture_extra_length: 56, 58, 60 nm
eta: 8.8, 9.1, 9.4 nm
```

不要优先大幅增加缝宽或减薄金膜；这些尝试已经表现为背景/匹配恶化。
