# 收敛优化与场分析记录 20260602

## 最新验收口径

用户在 2026-06-02 明确提高验收标准后，本结构不能只看“峰尖、背景低”。当前采用以下硬门槛：

- 透射率或用于验收的等效透射指标不得超过 1。
- 光谱不能出现明显震荡、振铃或旁峰杂乱。
- 改变 mesh accuracy、simulation time、auto shutoff、dt stability factor 等收敛参数后，峰位、峰高、线宽和背景必须基本一致。
- 透射谱必须由电场监视器佐证；电场图要能从物理机制上解释尖峰来源。
- 只有先通过上述门槛，才继续评价峰高、FWHM 和背景干净程度。

因此，早先将 `extra120` 直接作为“当前最佳”的结论已经作废。它只能作为强候选，不再作为验收结果。

## 电场监视器状态

已有一次单独 field profile monitor 运行，峰位与透射主峰同在 `1329.664 nm`，最大 `|E|^2` 约 `65.68`。但该场监视器位于透射侧平面，不能充分证明谐振器内部模式分布，因此只作为弱证据。

后续必须执行：

1. 移除透射监视器，每次只保留一个电场监视器。
2. 将电场监视器放在谐振器中面，当前脚本设定为 `field_monitor_z_nm=210`。
3. 输出峰位处 `|E|^2` 图、必要时输出 `Ex/Ey/Ez` 分量与相位。
4. 检查场增强是否集中在双环、八缝、对角失谐区域，并与准 BIC 暗模泄露路径相符。

只有场图能解释“暗模被小扰动打开辐射通道，金属屏蔽压低背景，开口控制外耦合”这一机制时，透射谱才可继续进入验收判断。

## 当前结论

截至本记录更新时，本结构仍处于“可行性验证中”，尚未验收通过。

可以保留该物理机制继续验证，理由是 `mesh2_ref` 与 `mesh2_long` 给出了稳定的尖峰、窄 FWHM 和低背景；但 `extra120/125/130/width34` 已因 `Abs(T)^2 > 1` 被严格拒收，不能作为最终结果。

下一步优先级：

1. 等待 `width32` 完成，判断峰值是否回到 `<=1` 且背景不震荡。
2. 若 `width32` 仍大于 1 或出现震荡，回到 `extra110/115` 做严格复验，而不是继续盲目缩缝。
3. 若存在候选通过透射硬门槛，再做谐振器中面电场监视器复验。
4. 若多次收敛参数改变仍导致光谱不一致，则判定当前 D4 样品不可验收，并切换到 DBR defect、guided-mode resonance 或 EIT-like 机制路线。
