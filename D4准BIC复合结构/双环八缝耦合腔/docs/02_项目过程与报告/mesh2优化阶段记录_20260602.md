# mesh2 优化阶段记录 2026-06-02

## 目标

目标仍然是：透射谱只有一个向上的尖锐强峰，带外背景接近 0，并且在用户给定的 mesh accuracy=2、simulation time=50000 fs、auto shutoff min=1e-7 等设置下可信。

## 已确认的运行约束

- 每次真实 FDTD 前检查 `fdtd-solutions`、`fdtd-engine-msmpi`、`mpiexec`、Python 驱动进程。
- 同一时间只允许一个 `.fsp` 仿真线程。
- 若发现已有 FDTD 线程，不启动新仿真；本轮所有仿真均为单线程顺序执行。

## D4 双环八缝耦合腔结论

mesh=1 下原始最优点为：

- `eta=9.14045 nm`
- `base_gap=14 nm`
- `inner_outer_shift=-10 nm`
- `screen_aperture_width=26 nm`
- `gold_thickness=90 nm`
- mesh=1 结果：`peak_abs2=0.8666`，`FWHM=2.67 nm`，`offband_p95=0.00311`

用户把 mesh accuracy 改为 2 后，峰值塌缩到约 `0.035`，说明原始 `16.86 nm` 最窄金属缝没有 mesh 收敛。

| 结构意图 | 关键参数 | 结果 |

阶段判断：mesh=2 下 D4 金属屏结构可以保持干净单峰，但峰值稳定卡在约 `0.2`。增大缝宽只提高背景，增大 eta 或改变内环相位均没有提高主峰。当前瓶颈更像是金属屏/硅环组合的吸收损耗与阻抗匹配上限，而不是单纯的准 BIC 泄露强度不足。

## DBR 缺陷腔分支结论

DBR/缺陷腔的公式路径是：

- 四分之一波层：`d_H=lambda_c/(4*n_H)`，`d_L=lambda_c/(4*n_L)`
- 缺陷腔：`d_cavity=m*lambda0/(2*n_cavity)`
- 目标机制：光子带隙压低背景，镜面对称缺陷态产生窄透射峰

FDTD 验证显示多个 DBR 候选虽然 `p95` 很低、主峰接近 1，但在 900-1700 nm 范围内存在多个接近 1 的窄旁峰。它们来自有限 chirped DBR 的多重透射态。因此 DBR 脚本已加入 `offband_max_abs2` 和 `side_peak_count` 判据，避免把“多高旁峰”误判为达标。

## 下一步建议

1. D4 路线若继续，需要改变损耗通道，而不是继续扫 `eta/slit/inner_shift`：可考虑把金属屏替换为低损耗介质反射屏，或在金属屏上引入相位补偿层。
2. DBR 路线若继续，需要抑制多重透射态：可考虑有损/吸收辅助的旁模抑制、非 chirped 窄带窗口外叠加反射结构，或用逆设计优化多层膜厚。
3. 当前已保留所有 `.fsp`、日志、Excel 和 PNG。D4 在 mesh=2 下最干净的单峰基线是 `mesh2_resolved_slit36_eta6d60_global_20260601_234627`。

## 2026-06-02 后续优化：从损耗到耦合重叠

### 约束

- 每次仿真前均检查 `fdtd-solutions.exe`、`fdtd-engine-msmpi.exe`、`mpiexec.exe` 和 Python 驱动进程。
- 始终只运行一个 `.fsp` 线程；若已有仿真线程，则等待其结束，不并行提交。
- 不做无依据扫参。每次改动必须对应一个物理假设或前一次迭代证据。

### 迭代结果

| 结构命名 | 关键改动 | 物理假设 | 结果 |
|---|---|---|---|
| Ag90 低损耗屏蔽基线 | `Ag (Silver) - Palik (1-10um)`, 厚度 90 nm, aperture width 36 nm, extra 58 nm | Ag 相比 Au 降低欧姆损耗，同时保持金属屏蔽背景 | `peak_abs2=0.2871`, `FWHM=3.67 nm`, `offband_p95=0.00548` |
| PEC 零损耗上限诊断 | 金属屏蔽改为 PEC | 估计去掉欧姆损耗后的峰高上限 | 触发电磁场发散，谱线峰值异常到 `1e5`，判定为非物理解，不作为优化依据 |
| Ag70 减薄屏蔽 | Ag 厚度 90 nm -> 70 nm | 若欧姆损耗仍是主瓶颈，减薄应提高峰高 | 失败：`peak_abs2=0.2052`, `offband_p95=0.00980`。减薄同时打开非共振泄漏，停止厚度减薄路径 |
| Ag90 extra90 | Ag90, aperture width 36 nm, extra 90 nm，实际 aperture length 200 nm | 增强金属开口与 D4 暗模的径向重叠积分，提高外部耦合 `gamma_e` | 有效：`peak_abs2=0.6502`, `FWHM=3.15 nm`, `offband_p95=0.00912`, 对比度 `71.3` |
| Ag90 extra110 当前最优 | Ag90, aperture width 36 nm, extra 110 nm，实际 aperture length 220 nm | 在已验证的耦合增强路径上继续接近临界耦合 | 当前最优：`peak_abs2=0.8327`, `FWHM=3.02 nm`, `offband_p95=0.01031`, 对比度 `80.7` |

### 机制判断

当前主峰来自 D4 双环八缝准 BIC 暗模被对角失谐 `eta=6.60 nm` 弱打开后的窄带辐射通道。背景由 Ag 金属屏蔽层抑制，尖峰由开口和硅环暗模的空间重叠耦合导出。

用单模耦合模近似：

`T_peak ~= 4 gamma_top gamma_bottom / (gamma_i + gamma_top + gamma_bottom)^2`

其中 `gamma_i` 是吸收损耗，`gamma_top/gamma_bottom` 是上下端口辐射耦合。Au -> Ag 的提升说明 `gamma_i` 重要；Ag70 的失败说明不能只靠减薄降低损耗，因为屏蔽不足会增加非共振背景。extra90/extra110 的提升说明当前更有效的方向是提高暗模与开口的重叠耦合，让 resonant channel 更接近临界耦合，同时维持金属屏蔽压背景。
