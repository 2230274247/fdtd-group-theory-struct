# 尖峰光谱结构生成经验文档

## 核心原则

不要先想“形状复杂一点”。先把目标拆成物理条件：

```text
背景干净 + 峰尖 + 透射强
```

对应到机制：

```text
低背景通道 + 高 Q 模态 + 合适外耦合
```

只有三者同时成立，才可能得到其余波长接近 0、峰很尖且向上的光谱。

## 标准工作流

1. 定义量化目标

```text
peak_abs2 或 T_peak: 越高越好
offband_p95: 越低越好
FWHM: 越窄越好
contrast = peak/offband_p95: 越大越好
edge_margin: 峰不能贴扫描边界
```

2. 先选低背景机制

可选机制：

- 金属屏蔽层 + 亚波长孔径
- 光子晶体 slab 带隙
- 高反射 guided-mode 背景
- 多层 DBR / Fabry-Perot 阻带
- 布里渊区折叠造成的禁带

如果背景没有先压低，后面再窄的模也只是高背景上的起伏。

3. 再选高 Q 模态机制

可选机制：

- 对称保护 BIC / 准 BIC
- Friedrich-Wintgen BIC
- EIT-like 暗亮模耦合
- 高阶 Mie 暗模
- 光子晶体缺陷态
- 环形 whispering-gallery-like 模
- guided-mode resonance

4. 最后设计外耦合

外耦合决定峰值和线宽之间的平衡：

```text
gamma_total = gamma_i + gamma_rad
FWHM proportional to gamma_total
peak strength depends on matching between gamma_i and gamma_rad
```

如果耦合太弱，峰很窄但不高；如果耦合太强，峰高但变宽。

## 常用公式

环形暗模尺寸：

```text
lambda0 ~= 2*pi*n_eff*R_eff / m
R_eff ~= m*lambda0/(2*pi*n_eff)
```

准 BIC 扰动：

```text
kappa proportional to delta
gamma_rad proportional to delta^2
Q_rad proportional to 1/delta^2
delta = perturbation_length / characteristic_length
```

线宽与 Q：

```text
Q ~= lambda0 / FWHM
FWHM ~= lambda0 / Q
```

耦合模透射：

```text
T(omega) = |t_bg + A/(i*(omega - omega0) + gamma_i + gamma_rad)|^2
```

设计判断：

- `t_bg` 大：先处理背景，不要继续微调暗模。
- `FWHM` 大：减小扰动或提高模态 Q。
- 峰值低：增加外耦合或调暗亮模匹配。
- 峰贴边界：调整尺度，不要误判成好峰。

## 反馈规则

仿真后按结果反推下一步：

```text
峰位偏长波: 缩小结构尺寸，或提高等效折射率估计后重新反推半径
峰位偏短波: 放大结构尺寸，或降低等效折射率估计
背景高: 加屏蔽层、带隙结构、DBR，或提高填充率
峰宽: 减小对称破缺 delta，或换更高 Q 机制
峰弱: 增大 delta，或增强孔径/亮模耦合
多峰杂乱: 提高对称性、减少自由度、缩小扫描窗口
峰值异常大: 同时检查标准 power T 和 |T|^2，确认归一化方式
```

## 仿真纪律

- 每次真实仿真前必须检查是否已有 FDTD/Lumerical 进程。
- 每次只能一个线程仿真。
- 如果检测到已有 `.fsp` 正在运行，当前线程直接退出并记录原因。
- 保留原始母版 `.fsp`。
- 每个候选仿真后的 `.fsp`、Excel、PNG、JSON/CSV 日志都要保留。
- 如果高精度 full 超时，停止该线程，记录为未完成，不把它当作验证通过。

## 结构生成模板

每次生成新结构时，必须先写下：

```text
1. 目标指标
2. 低背景机制
3. 高 Q 模态机制
4. 外耦合方式
5. 公式估算
6. 参数扫描范围
7. 预期失败模式
8. 仿真反馈规则
```

然后才允许搭建 `.fsp`。

## 不局限于本次结构

本次命中使用的是：

```text
Au 屏蔽层 + D4 环缝孔径 + 硅双环准 BIC
```

后续可以换成其他组合，例如：

- 光子晶体带隙 + 缺陷腔
- DBR 背景 + 中央暗模
- 高折射率 guided-mode resonance + 对称破缺
- 金属孔径 extraordinary transmission + 介质暗模
- 布里渊区折叠 + 超胞扰动

但目标始终不变：背景干净、峰尖、透射强。
