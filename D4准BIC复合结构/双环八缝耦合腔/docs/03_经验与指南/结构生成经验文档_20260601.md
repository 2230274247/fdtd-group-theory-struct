# 结构生成经验文档 2026-06-01

## 工作流程

后续继续生成结构时，按这个闭环执行：

```text
明确目标 -> 选择物理机制 -> 用公式估算尺寸 -> 搭建结构 -> 单线程仿真验证 -> 根据失败模式反推下一轮
```

本次最终目标的量化口径：

```text
peak Abs(T)^2 >= 0.85
FWHM <= 8 nm
offband_p95 Abs(T)^2 <= 0.03
contrast >= 30
```

注意：这里的 `Abs(T)^2` 是用户在 Lumerical visualizer 中选择 `T:T / T` 后施加 `Abs^2` 看到的谱线。

## 成功经验

成功组合是：

```text
低背景金属屏 + D4 准 BIC 暗模 + 双环相位/阻抗匹配
```

有效参数不是“越强耦合越好”，而是临界匹配：

```text
eta = 9.14045 nm
inner_outer_shift = -10 nm
Au thickness = 90 nm
screen slit width = 26 nm
```

结果：

```text
peak = 0.8666
FWHM = 2.67 nm
p95 background = 0.00311
```

## 公式和判断

环形暗模尺寸：

```text
lambda0 ~= 2*pi*n_eff*R_eff/m
R_eff ~= m*lambda0/(2*pi*n_eff)
```

准 BIC 扰动：

```text
delta = eta/R_eff
gamma_rad proportional to delta^2
Q_rad proportional to 1/delta^2
```

二端口耦合模型：

```text
T(omega) = |t_bg + A/(i*(omega - omega0) + gamma_i + gamma_rad)|^2
FWHM proportional to gamma_i + gamma_rad
```

设计含义：

```text
t_bg 高 -> 先压背景，不要微调暗模
峰值低但背景干净 -> 调外耦合/相位匹配
峰值高但多峰 -> 增加单模选择性，不要只看 p95
峰变宽 -> 扰动过强或出现直接连续通道
峰值降低且线宽变化大 -> 结构相位失配，不是简单耦合强弱问题
```

## 本次失败模式

1. 纯硅 D4 双环：

背景太高，不能满足“其余波长接近 0”。

2. 加大金属缝或减薄金膜：

会打开直接通道，或改变金属缝纵向相位，导致峰值降低、线宽变宽。

3. 增大 eta 到 12 nm：

没有把峰值抬高，说明原 eta 已接近暗模辐射泄漏最佳点。

4. inner_outer_shift = +10 nm：

峰值下降，说明内外环相位调节有方向性。

5. chirped DBR defect cavity：

传输矩阵和 FDTD 都显示可以产生强峰，但宽波段内容易出现多个高旁峰。对“只要一个干净尖峰”的目标，不应只用 p95 背景判断，必须检查 side peak max。

## 下一次继续优化的优先级

围绕已达标结构做小步局部搜索：

```text
inner_outer_shift: -12, -10, -8 nm
gold_thickness: 88, 90, 92 nm
screen_aperture_extra_length: 56, 58, 60 nm
eta: 8.8, 9.1, 9.4 nm
```

每次只改一个主参数，避免无法判断物理原因。

## 仿真纪律

每次真实 FDTD 前必须检查：

```text
fdtd-solutions
fdtd-engine
fdtd-engine-msmpi
fdtd-run-local
mpiexec
lumerical
python/python3.13
```

若已有运行中的 FDTD/Lumerical 或脚本仿真锁，当前线程直接退出。只有确认旧 PID 不存在的 stale lock 才能清理。

每次仿真保留：

```text
候选 .fsp
transmission Excel
PNG 光谱图
metrics.json
manifest.csv
stdout/stderr log
```

## 经验结论

本次最重要的结论是：对于“低背景 + 尖峰 + 高透射”，不能只追求高 Q，也不能只追求大开口。真正有效的是：

```text
先用屏蔽/带隙压低背景
再用对称保护暗模控制线宽
最后用小参数调相位和外耦合，使暗模在单一频率高效出射
```
