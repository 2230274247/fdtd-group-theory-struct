# 六臂星扰动脚本说明

真实 `.fsp` 参数：

- 对象：3 个 `Si_arm`
- 每个 `Si_arm` 是穿过中心的矩形，因此实际代表一对相对臂
- 母版臂宽：`110 nm`
- 母版臂长：`620 nm`
- 厚度：`420 nm`
- 衬底：`900 nm x 900 nm x 1000 nm`
- 透射监视器：`T`

## 重要说明

当前 `.fsp` 并没有 6 个独立的单臂对象，而是 3 个对臂矩形。因此：

- “单臂变化”在当前脚本中实现为改变 1 个对臂矩形；
- “对臂变化”与当前几何对象最吻合；
- “交替两组臂变化”只能作为近似扰动，若未来需要严格交替 6 臂，需要重建母版为 6 个独立臂对象。

## 脚本

- `单臂变化扰动`：改变 1 个 `Si_arm` 宽度
- `交替两组臂变化扰动`：近似改变部分 `Si_arm` 宽度
- `对臂变化扰动`：改变 1 个对臂矩形宽度，近似 `C6 -> C2`
- `所有臂同步缩放扰动`：三个 `Si_arm` 同步改变长度，保持 `C6`

所有结果保存到 `六臂星\results\扰动名\run_模式_时间戳\`。
