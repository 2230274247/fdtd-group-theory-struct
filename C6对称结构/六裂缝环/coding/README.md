# 六裂缝环扰动脚本说明

真实 `.fsp` 参数：

- 外环 `Si_outer_ring` 半径：`310 nm`
- 内孔 `air_inner_ring` 半径：`200 nm`
- 6 条 `air_slit`
- 裂缝中心半径：`280 nm`
- 母版裂缝宽度：`45 nm`
- 母版裂缝长度：`150 nm`
- 厚度：`420 nm`
- 衬底：`900 nm x 900 nm x 1000 nm`
- 透射监视器：`T`

## 脚本

- `改单裂缝扰动`：改变 1 条裂缝宽度，`C6 -> C1`
- `交替裂缝扰动`：改变 1/3/5 三条间隔裂缝宽度，`C6 -> C3`
- `对裂缝变化扰动`：改变 1/4 两条相对裂缝宽度，`C6 -> C2`
- `单点缺口扰动`：额外插入一个局部 etch 缺口，`C6 -> C1`
- `六裂缝同步宽度扰动`：六条裂缝同步宽度扫描，保持 `C6`

所有结果保存到 `六裂缝环\results\扰动名\run_模式_时间戳\`。
