# 六柱环扰动脚本说明

真实 `.fsp` 参数：

- 对象：6 个 `Si_pillar`
- 柱心半径：`240 nm`
- 柱半径：`75 nm`
- 厚度：`420 nm`
- 衬底：`900 nm x 900 nm x 1000 nm`
- 透射监视器：`T`

## 脚本

- `改单个柱子扰动`：改变 1 个柱子半径，`C6 -> C1`
- `交替两组柱子扰动`：改变 1/3/5 三个间隔柱子半径，`C6 -> C3`
- `对边两柱变化扰动`：改变 1/4 对边柱子半径，`C6 -> C2`
- `单柱偏移扰动`：单个柱子沿径向向外移动，`C6 -> C1`
- `六柱同步半径扰动`：六柱同步半径扫描，保持 `C6`

所有结果保存到 `六柱环\results\扰动名\run_模式_时间戳\`。
