# 群论_struct 目录内容全面总结

> 项目全称：基于群论对称性的光子结构母结构数据库  
> 适用领域：光子结构、GMR / quasi-BIC / Fano 共振、高 Q 窄线宽滤波器、基于目标光谱的逆向设计  
> 更新时间：2026-05-13

---

## 一、项目目标与核心思想

该项目围绕一条核心数据链展开：

```
高对称母结构 → 施加可控微扰 → 降群 → FDTD 仿真 → 光谱分析 → 逆向设计
```

通过系统记录不同旋转对称性（C2、C3、C4、C6、近径向 C∞）的母结构在受到对称性破缺扰动后的光谱响应变化，建立"对称性家族 + 降群路径 + 扰动强度（delta）+ 几何参数 → 光谱响应"的映射关系。

核心物理问题：**对称性保护**——高对称结构存在模式因对称性而不与外界辐射耦合（暗模/BIC），施加扰动破缺对称性后，暗模"亮化"，辐射泄露增强，共振线宽变宽。研究的目标是追踪"delta 增大 → Q 下降 → FWHM 变宽"这一规律，并在小 delta 区域寻找高 Q 窄峰。

## 二、顶层目录结构

```
群论_struct/
├── 群论母结构数据库_中文/    ← 数据库文档、表格模板、维护脚本、分析输出
```

## 四、各类文件详解

### 4.1 构建脚本（`scripts/*_build_*.py`）

**作用**：通过 Lumerical Python API 在 FDTD 中自动构建母结构模型。每个脚本定义 META 字典（周期 0.9 um、Si 高度 0.42 um、衬底 1.0 um、波长 900-1700 nm、采样 501 点、仿真 1000 fs），放置 PlaneSource（正入射 -z 方向）和透射监视器，设置 x/y 周期边界 + z PML，运行仿真后保存 `.fsp`、导出透射谱 PNG 和 CSV。

每种结构 4 个版本，分布在 scripts/ 目录下。

### 4.2 结构说明文档（`docs/*_note_*.md`）

**作用**：每份文档记录该母结构的对称性类别、几何组成、关键参数表、源/监视器设置、适用评价（"最优先推荐"/"适合讲 C4 降群"等）、允许破缺方式、初步仿真结果（status、T_peak、lambda_peak_nm）和风险说明。例如双柱的 T_peak=0.0804，lambda_peak=1353.5 nm，十字的 T_peak=0.0053。

### 4.3 透射谱数据（`data/*.csv`）

**作用**：两列（Wavelength_nm, Transmittance_T）原始透射谱，501 行，范围 900-1700 nm。Transmittance 为负值（-0.98 量级），可能是 dB 形式或未归一化值。可直接被`提取光谱指标.py`读取分析。

### 4.4 仿真结果（`results/*.json`）

**作用**：JSON 格式摘要，包含三个字段：status（simulated/failed）、peak_T（峰值透过率）、peak_nm（峰值波长）。每个结构每批次一个，共约 24 个。属于初步初扫结果，标注为"低风险初扫，不作为最终高保真论文结论"。

### 4.5 透射谱截图（`png/*.png`）

**作用**：从 Lumerical 摄取监视器直接截图的透射谱图像，便于快速浏览而无需打开 FDTD 软件。

### 4.6 FDTD 模型文件（`fsp/*.fsp`）

**作用**：Lumerical FDTD Solutions 原生格式，可被软件直接打开继续编辑。后续所有扰动扫描脚本均基于这些 `.fsp` 的副本进行修改操作。

## 五、扰动扫描代码体系

### 5.1 公共扫描模块（sweep common）

位于各对称群顶层目录，提供通用参数扫描框架：

| 文件 | 位置 | 功能 |
|------|------|------|
| `c2_sweep_common.py` | C2对称结构/ | C2 族通用：复制母版 fsp → 校验 SHA256 → 修改几何 → 运行仿真 → 保存结果 |
| `c3_sweep_common.py` | C3对称结构/ | C3 族通用，同上 |
| `c6_sweep_common.py` | C6对称结构/ | C6 族通用，同上 |
| `four_hole_square_common.py` | C4/四孔方块/coding/ | 四孔方块专用工具 |
| `four_slit_ring_common.py` | C4/四裂缝环/coding/ | 四裂缝环专用工具 |
| `four_pillar_cluster_common.py` | C4/四柱簇/coding/ | 四柱簇专用工具 |

这些模块包含：Lumerical API 导入、单位换算（nm/um）、中文时间戳、SHA256 文件校验（防止误改源 fsp）、时长格式化、文件查找等公共函数。

### 5.2 扰动扫描脚本（共 60+ 个）

每个扰动类型对应一个中文命名的子目录和一个 `run_fdtd_*_sweep.py` 主脚本。统计如下：

| 对称群 | 母结构数 | 扰动脚本数 | 扰动类型示例 |
|--------|:--------:|:----------:|--------------|
| C2 | 5 | 20 | 半径差、位置差、高度差、间距扫描、梁宽差、梁长差、脊宽差、脊高差、转角差、长轴差、短轴差、开孔扰动等 |
| C3 | 3 | 12 | 单柱半径变化、单点偏移、两柱同改、同步半径扫描、单臂长度/宽度/转角差、单裂缝宽度/角度/长度 |
| C4 | 5 | 22 | 横竖臂长/宽差、单臂变化/开槽、偏心内孔、边宽差、外框长宽差、单孔半径/偏移、对角成对变化、孔距扫描、单裂缝宽/角/长、对边裂缝成对变化 |
| C6 | 3 | 14 | 单柱/对柱/交替柱变化、单臂/对臂/交替臂变化、单裂缝/对裂缝/交替裂缝变化、六柱/裂缝同步扫描 |
| 近径向 | 2 | 5 | 偏心孔、单侧缺口、椭圆化、偏心内孔、环宽不均 |

### 5.3 扰动类型分类

- **形变类**（改变尺寸）：半径差、梁宽差、脊宽差、长轴差、短轴差、臂长差、臂宽差、孔半径、裂缝宽度、边宽差
- **位移类**（改变位置）：位置偏移、单孔/单柱偏移、内孔偏心、非对称位移
- **拓扑类**（改变连通性）：开孔、开槽、开裂缝、缺口切割、转角变化
- **同步类**（保持对称对照组）：所有元素同步缩放，不改变群，用于区分"尺度效应"与"破缺效应"

所有扰动使用**归一化 delta** 定义（如 delta=(r1-r2)/r0），使不同类型、不同尺度的结构之间可以横向比较。

## 六、HTML 文件（4 个）

### 6.1 FDTD 群论结构结果查看器（`结果查看器_html/index.html`）

Plotly.js 单页应用，左右分栏布局。左侧为文件夹树/结构选择器，右侧为 Plotly 透射谱对比图。支持多选样本叠加对比、Abs^2/dB 模式切换。配套 JSON 配置文件（`view_state.json`、`scan_cache.json`、`fdtd_controller_overrides_*.json`）存储缓存和视图状态。

### 6.2 拓扑相变候选分析（`结果查看器_html/topology_transition_analysis.html`）

专门分析不同扰动强度下透射谱定性变化的 HTML 工具，聚焦识别共振峰出现/消失、模式分裂、Fano 线型转变等拓扑相变特征。

### 6.3 模式接力现象分析（`近径向高对称结构/圆环/transmission_mode_relay_analysis.html`）

独立 HTML 分析报告，针对圆环结构在偏心内孔扰动下的"模式接力"现象，包含理论解释、图解和 Plotly 交互式光谱图。

### 6.4 母结构图库（`群论母结构数据库_中文/文档与说明/母结构图库原始网页.html`）

按对称性分类卡片式展示所有母结构的可视化图库页面。

## 十、建议的推进路线

第一阶段优先推动以下 3 条主线（推荐优先级 A）：

1. **C2 双柱 / 左右半径差** → 建立 C2→C1 降群的 delta-Q 基线关系
2. **C4 十字 / 横竖臂长度差** → 建立 C4→C2 降群主线
3. **C4 方环 / 偏心内孔** → 研究环模泄露和 Fano 线型

第二阶段扩展：双脊、双椭圆、四柱簇、四孔方块

关键任务：对小 delta 区域（0.02-0.06）进行高分辨率细扫，寻找 quasi-BIC / 高 Q 窄峰区域。
